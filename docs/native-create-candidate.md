# Isolated native sketch population candidate

Fork patch 10 (`734a50c`, tree `6510ded9`) adds one experimental editor transaction for the temporary Part Studio `4e078dec822b4e509616b1cb/af0627de07264acf086e646a/9a062f0eef8bb961f8c84f8e`. It uses the existing FSGen source `fixtures/native/minimal_plate.fs`, normal UI allocation of a fresh blank Top sketch, then typed `GBTUiSpecifyFeature` and `GBTUiCommit` through the native bridge. The generator constructs fresh serializer node IDs and sketch-local line/constraint IDs from the source. It never reuses IDs from the observed control rectangle.

The H2 command is `h2cad experimental-sketch-populate fixtures/native/minimal_plate.fs --did 4e078dec822b4e509616b1cb --wid af0627de07264acf086e646a --eid 9a062f0eef8bb961f8c84f8e --tab-id <exact-active-tab> --bridge-config <paired-config> --journal <same-pinned-journal>`. The paired config must point at that journal. A restarted patched Python bridge and reloaded, reconnected extension must advertise `h2_native_sketch_populate_server_v1` and `h2_native_sketch_populate_page_v1` before H2 creates an intent. The target must have exactly one **empty, active, UI-allocated Top sketch**; the current manually drawn rectangle is deliberately ineligible. The tester owns any live setup and the single trial after root/Astra review.

The CLI compiles the source offline and rejects any disagreement among its summary, entities, constraints, parameter types, Top-plane reference, extrusion dependency, or literal 5 mm depth. It reads a fresh exact-target element revision and active sketch/plane binding; writes a durable operation intent; sends one page transaction; then reads state independently. It checks four 40×20 mm nonconstruction line segments, eleven editor-native geometric/dimension constraints, unchanged plane query and unrelated tree nodes, idle connection, and revision advance. Uncertain responses or changed unrelated content leave the journal unresolved. `h2cad reconcile` gives a read-only diagnostic for an uncertain sketch action; it never retries.

Evidence level remains **experimental definition observation**. The local fake editor proves typed serialization, revision refusal, and journal behavior, but cannot prove the live editor accepts the full sketch change or that its constraint solver anchors the origin. The current editor readback has no complete native regeneration contract. Tester must inspect a fresh constraint graph, open and edit both dimensions, confirm fully constrained geometry and no unrelated change. The same CLI does not yet initiate Sketch/Top, create an extrusion, or generate the full car. Those are the next required implementation stages, not achievements of this patch.
